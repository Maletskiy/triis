# ТРИИС — калькулятор ИИС

**Сайт:** https://triis.vercel.app · **Домен:** triis.ru (в планах) Считает выгоду от индивидуального инвестиционного счёта: налоговый вычет на взнос,
налог на прибыль при закрытии, рост капитала по годам и реальную доходность с поправкой
на инфляцию. Сравнивает три типа счёта — ИИС-3, тип А и тип Б — на одних и тех же
параметрах.

## Что внутри

- **Движок расчёта** — `src/lib/calc.ts` + правила 2026 года в `src/lib/rules.ts`:
  база вычета 400 000 ₽/год, ставка НДФЛ по прогрессивной шкале, лимит освобождения
  прибыли 30 млн ₽ на ИИС-3, лимит взноса 1 млн ₽ на старых ИИС, срок владения 5 лет
  для счетов 2024–2026 и +1 год ежегодно до 10.
- **Дизайн** — на примитивах [mishanaer/deslop](https://github.com/mishanaer/deslop):
  цвета `#111` с лестницей альф, SB Sans Interface, шкала 40/32/24/20/16/14/13,
  радиусы 20–22, тонкие границы вместо теней. Токены — `src/design/primitives.css`.
- **Слайдеры без бегунка** — дорожка из столбиков: при быстром протаскивании
  пройденные столбики вскипают и затухают (эффект wake из bencho.dev).
- **Лайк в подвале** — сердце с хлопком, кольцом, конфетти и счётчиком;
  состояние хранится в браузере (`localStorage`), общего счётчика пока нет.
- **Числа-одометры** — меняющиеся суммы прокручивают цифры, а не подменяют текст.
- **UI** — табы со скользящей плашкой, сворачиваемые секции с плавной анимацией высоты,
  нижняя плашка с итогом, шторка с деталями, тосты подтверждения, копирование ссылки
  с галочкой. Всё по мотивам Qrix.
- **Счёт по выгоде**: «ИИС-3», «Тип А» (вычет на взнос), «Тип Б» (доход без налога) —
  с пояснением, что даёт каждый тип.
- **Дата открытия** — календарь: от неё считаются минимальный срок и дата, когда
  счёт можно закрыть без потери льгот (ИИС открывают с 2015 года).
- **План взносов** — одна сумма на все годы или своя сумма по каждому году.
- **Частота реинвестирования** — год, полгода, квартал или месяц: доход
  капитализируется внутри года, итог растёт.
- **Ставка НДФЛ** — по умолчанию предельная по доходу; тоглом включается ручная
  13/15/18/20/22%.
- **Параметры в адресе** — расчёт можно переслать ссылкой.
- **Разбивка по годам** — таблица показывает взнос, вычет и год, в котором его вернут.
- **Выгрузка** — CSV с разбивкой по годам и PDF через печать: в отчёт попадают
  параметры расчёта, итог, график и таблица.
- **Синяя палитра** (по мотивам bcs.ru/iis) на CSS-токенах; плашка активного таба — чёрная.
- **Контролы как на референсе**: подпись, крупное значение и слайдер в одной плашке;
  базовый кегль 19 px.

## Команды


## Деплой

Прод живёт на хостинге reg.ru: `https://triis.ru`, каталог
`/var/www/u3695402/data/www/triis.ru`. Пуш в `main` запускает
`.github/workflows/deploy-regru.yml`: сборка, проверки, выгрузка `dist` по SSH
через rsync. Вручную — `npm run deploy:regru`.

Ключ и адрес хостинга лежат в секретах репозитория (`REGRU_SSH_KEY`,
`REGRU_HOST`, `REGRU_USER`, `REGRU_PATH`). Правки `.htaccess` проверяет
`scripts/check-htaccess.sh`: типограф однажды заменил там дефис на тире,
и Apache начал отдавать 500 на все адреса.

Отдельно `.github/workflows/checks.yml` на каждый пуш и PR прогоняет
`npm run check` и сборку — это проверка, а не деплой.

## Допущения

- Взнос делается в начале года, вычет приходит в начале следующего.
- Прибыль облагается по двухступенчатой шкале 13 / 15% как отдельная база.
- Вычет на взнос не может превышать уплаченный за год НДФЛ.
- Комиссии, купоны и дивиденды не учитываются.

Правила зафиксированы на 2026 год. Это не инвестиционная рекомендация.

## Поиск и ИИ-краулеры

Сайт — клиентское приложение, поэтому HTML собирается заранее:
`npm run build` после `vite build` запускает `scripts/prerender.mjs`, который
рендерит те же компоненты на Node и вставляет разметку в `dist/index.html`
и `dist/privacy.html`. Так поисковики, GPTBot, ClaudeBot и PerplexityBot видят
текст без JavaScript. Клиент по-прежнему монтируется через `createRoot`
и заменяет разметку своей.

Что ещё есть:

- блок текста под калькулятором (`src/components/About.tsx`) — объяснение
  и восемь частых вопросов, тексты служат источником для разметки;
- JSON-LD в `index.html`: WebSite, Organization, WebApplication; FAQPage
  собирается в пререндере из того же массива вопросов;
- `public/llms.txt` — краткая выжимка для языковых моделей;
- `public/robots.txt` — открыт для ИИ-краулеров, со ссылкой на карту сайта;
- `public/sitemap.xml` — дата последнего изменения проставляется при сборке.

Проверка: `npm run check:seo` после сборки. Она смотрит заголовки, описание,
canonical, Open Graph, наличие одного `h1`, объём статического текста, разметку
Schema.org, совпадение вопросов из FAQPage с текстом страницы, а также
`robots.txt`, `sitemap.xml`, `llms.txt` и размер картинки превью
