# Triis — калькулятор ИИС

**Сайт:** https://triis.vercel.app · **Домен:** triis.ru (в планах) Считает выгоду от индивидуального инвестиционного счёта: налоговый вычет на взнос,
налог на прибыль при закрытии, рост капитала по годам и реальную доходность с поправкой
на инфляцию. Сравнивает три типа счёта — ИИС-3, ИИС-1 и ИИС-2 — на одних и тех же
параметрах.

## Что внутри

- **Движок расчёта** — `src/lib/calc.ts` + правила 2026 года в `src/lib/rules.ts`:
  база вычета 400 000 ₽/год, ставка НДФЛ по прогрессивной шкале, лимит освобождения
  прибыли 30 млн ₽ на ИИС-3, лимит взноса 1 млн ₽ на старых ИИС, срок владения 5 лет
  для счетов 2024–2026 и +1 год ежегодно до 10.
- **UI** — табы со скользящей плашкой, сворачиваемые секции с плавной анимацией высоты,
  нижняя плашка с итогом, шторка с деталями, тосты подтверждения, копирование ссылки
  с галочкой. Всё по мотивам Qrix.
- **Параметры в адресе** — расчёт можно переслать ссылкой.
- **Синяя палитра** (по мотивам bcs.ru/iis) на CSS-токенах; плашка активного таба — чёрная.
- **Контролы как на референсе**: подпись, крупное значение и слайдер в одной плашке;
  базовый кегль 19 px.

## Команды

```bash
npm install
npm run dev        # локальная разработка
npm run build      # прод-сборка в dist/
npm run check      # проверки движка на контрольных примерах
npm run ui-check   # проверки интерфейса в headless Chrome (нужен Chrome)
npm run deploy     # ручная выкладка на Vercel (нужен VERCEL_TOKEN)
```

## Деплой

Прод выкатывается самим Vercel: проект привязан к репозиторию `Maletskiy/triis`,
пуш в `main` — деплой на прод, PR — превью-деплой. Сборка на стороне Vercel:
`npm ci` → `npm run build` → `dist`.

Параллельно `.github/workflows/checks.yml` на каждый пуш и PR прогоняет
`npm run check` и сборку — это проверка, а не деплой.

## Допущения

- Взнос делается в начале года, вычет приходит в начале следующего.
- Прибыль облагается по двухступенчатой шкале 13 / 15% как отдельная база.
- Вычет на взнос не может превышать уплаченный за год НДФЛ.
- Комиссии, купоны и дивиденды не учитываются.

Правила зафиксированы на 2026 год. Это не инвестиционная рекомендация.
